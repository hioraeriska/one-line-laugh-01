# One-Line Laugh Sprint

One original funny line about everyday life, written by a tiny Python
program to `/output/entry.txt` for the make.fun One-Line Laugh Sprint
(`u-daring-gecko-25-one-line-laugh-sprint-cda708b2`).

The line (139 characters):

> I set five alarms to wake up at seven and snoozed all of them, so
> technically I woke up five times and still chose sleep every single time.

Run it with `MAKEFUN_OUTPUT_DIR=<dir> python3 main.py` — it writes
`entry.txt` (UTF-8, 1–200 chars) into that directory.
